
# Pointer Assignment

## Description

This project demonstrates the use of pointers in C programming. It focuses on storing memory addresses, accessing values through pointers, and modifying data using pointer variables.

## Files

- `main.c` - Test file
- `set_string.c` - Function that sets the value of a pointer to a string
- etc

## Compilation

gcc -Wall -Werror -Wextra -pedantic main.c set_string.c -o output
