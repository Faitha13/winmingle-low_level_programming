This is a readme file about my struct and typedef practices


1. dog.h – Defined the "struct dog" structure and created "dog_t" as an alias using "typedef".

2. init_dog – Implemented a function to initialize a dog structure with a name, age, and owner.

3. print_dog – Created a function to display the contents of a dog structure, handling "NULL" values safely.

4. new_dog – Developed a function that dynamically allocates memory and creates a new dog with copies of its name and owner.

5. free_dog – Implemented a function to properly free all memory allocated for a dynamically created dog.

6. Memory Management and Structures – Practiced the use of structures, pointers, typedef, dynamic memory allocation, and safe memory deallocation in C.
